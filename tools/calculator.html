d_S(UV) must equal 2 for string selection
❌ Test 3: Ghost Central Charge

If c_ghost ≠ −15 for the superstring, then D ≠ 10. This would require a modification to the ghost field theory (different statistics or additional ghost sectors).

c_ghost = c_bc + c_βγ = −26 + 11 = −15
❌ Test 4: Modular Invariance

If the worldsheet partition function does not transform correctly under SL(2,ℤ) — specifically if S² ≠ −I or (ST)³ ≠ −I — the modular bootstrap fails.

S = [[0,−1],[1,0]], T = [[1,1],[0,1]]; S² = −I, (ST)³ = −I
❌ Test 5: Weyl Tensor in 4D

If propagating gravity exists in fewer than 4 dimensions, the 4+6 split is wrong. W(n) = n(n+1)(n+2)(n−3)/12 gives W(3) = 0 and W(4) = 10. If an alternative formula applied, the dimensional selection changes.

W(4) = 10 (must be non-zero for propagating gravity)
❌ Test 6: Extra Large Dimensions

If experiments detect extra spatial dimensions beyond 3+1 at accessible energy scales, the 4+6 compactification scheme is wrong — the extra 6 dimensions would not be compact.

❌ Test 7: Supersymmetry

CSU predicts N=1 SUSY on the worldsheet. If a consistent string theory with N=0 or N≥2 worldsheet SUSY is found that reproduces the Standard Model, the uniqueness argument fails. (Note: SUSY breaking scale is separate — SUSY could exist at very high energy.)
